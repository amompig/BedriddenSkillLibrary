# planning-and-task-breakdown

> 把一份 spec 拆成數十個可獨立驗證的小任務，附上驗收條件與任務相依關係。

**Slash command**：`/plan`

## 階段

**Plan — 拆解**

## 用途

把一份 spec 拆成數十個可獨立驗證的小任務，附上驗收條件與任務相依關係。

## 觸發時機

手上已經有 spec、需要變成可以一個一個打勾的實作單位時。

## 怎麼用

Skill 會把 spec 轉成類似 Linear ticket 的結構：每個 task 含輸入、輸出、驗收條件、前置相依、預估大小。
