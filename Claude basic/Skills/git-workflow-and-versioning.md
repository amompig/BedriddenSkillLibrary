# git-workflow-and-versioning

> Trunk-based development、原子 commit、變更大小 ~100 行、commit 即存檔點（能獨立 revert）。

## 階段

**Ship — 有信心地上線**

## 用途

Trunk-based development、原子 commit、變更大小 ~100 行、commit 即存檔點（能獨立 revert）。

## 觸發時機

任何程式碼變更（always）。

## 怎麼用

Skill 強制：每個 commit 一件事、訊息寫清楚「為什麼」、main 永遠可 ship、不開長壽 feature branch。
