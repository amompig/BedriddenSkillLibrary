# Cloud Run Basics

> Cloud Run（無伺服器容器）部署與管理：打包容器、設定擴縮、掛網域、環境變數。

## 分類

**Google Cloud**（google/skills repo 目前唯一的分類）

## 用途

Cloud Run（無伺服器容器）部署與管理：打包容器、設定擴縮、掛網域、環境變數。

## 觸發時機

要部署一個 HTTP 服務但不想管主機；或想讓服務自動擴縮到 0 節省成本時。

## 怎麼用

安裝到本機後，Claude 會在偵測到相關關鍵字（如 `cloud run basics`、對應產品名稱）時自動載入並依 SKILL.md 的步驟操作。

```bash
# 單獨安裝這個 skill
npx skills add google/skills/skills/cloud/cloud-run-basics

# 或裝整組 Google Cloud skills
npx skills add google/skills
```
