# shipping-and-launch

> 發佈前檢查清單、feature flag 生命週期、分階段推出（canary → % roll-out → full）、回滾程序、監控告警。

**Slash command**：`/ship`

## 階段

**Ship — 有信心地上線**

## 用途

發佈前檢查清單、feature flag 生命週期、分階段推出（canary → % roll-out → full）、回滾程序、監控告警。

## 觸發時機

準備把一個變更部署到 production 之前。

## 怎麼用

輸入 `/ship` 觸發。Skill 會強制通關所有檢查：測試綠、文件更新、feature flag 配好、監控儀表板就緒、回滾計畫寫好。
