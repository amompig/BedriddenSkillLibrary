# browser-testing-with-devtools

> 透過 Chrome DevTools MCP 拿到瀏覽器執行時的真實資料：DOM 結構、console log、network request、performance trace。

**Slash command**：`/test`

## 階段

**Verify — 證明可運作**

## 用途

透過 Chrome DevTools MCP 拿到瀏覽器執行時的真實資料：DOM 結構、console log、network request、performance trace。

## 觸發時機

建立或除錯瀏覽器應用；需要驗證「在真實使用者環境下」是否正常運作時。

## 怎麼用

Skill 會指示 Claude 開啟 Chrome DevTools MCP、跑腳本、擷取執行時資料、再基於真實資料修正程式。
