# source-driven-development

> 每個框架決策都要以官方文件為依據，並在 code 或 PR 描述中標註來源。未經驗證的內容要明確標出「⚠️ 未證實」。

## 階段

**Build — 寫程式**

## 用途

每個框架決策都要以官方文件為依據，並在 code 或 PR 描述中標註來源。未經驗證的內容要明確標出「⚠️ 未證實」。

## 觸發時機

使用新框架、新 API、或有版本敏感的功能時。避免 Claude 編造過時 API。

## 怎麼用

Skill 會強制 Claude 在寫框架相關程式碼時先拉官方 docs、再寫；並在關鍵段落放來源 URL 註解。
