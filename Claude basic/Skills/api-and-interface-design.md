> Contract-first 設計、Hyrum's Law（所有可觀察行為終將被依賴）、One-Version Rule、錯誤語意、邊界驗證。

## 階段

**Build — 寫程式**

## 用途

Contract-first 設計、Hyrum's Law（所有可觀察行為終將被依賴）、One-Version Rule、錯誤語意、邊界驗證。

## 觸發時機

Skill 要求先產出 schema / OpenAPI spec、明確定義錯誤 code 與 HTTP 語意、規劃向後相容策略。
