# Competitor Analysis & 36-Month Moat Check (Internal Variant)

This chapter is mandatory at board level when any "surprise" relates to the competitive or technology landscape. It is optional at department level. It is not run at team or all-hands level.

The internal variant differs from the external variant in two ways:
1. **Full transparency**: the weighted score appears in the deck. Internal audiences can handle (and benefit from) the raw analysis.
2. **Surprise-triggered**: at board level, every surprise must be tagged with whether it triggered a moat re-check. Re-checks must be in the deck if triggered.

## When to run a moat re-check

Run the re-check when:
- Any surprise reported in the "surprises this quarter" section involves a major incumbent shipping a competitive feature, a new entrant being well-funded, an acquisition that changes the competitive landscape, or a technology shift that closes a gap you previously had
- It is the annual board meeting (annual full re-check is required regardless of surprises)
- The user explicitly asks for it

Do not run the re-check at every quarterly board meeting if nothing has changed — that produces fatigue and dilutes the impact when a real re-check is needed.

## Section structure (when run)

### 1. Surprise tagging

For every surprise reported in "surprises this quarter," include this tag:

```
Surprise: [event description]
Moat re-check triggered: [Y / N]
Reason: [if N, why this surprise does not change the moat picture; if Y, brief preview of which dimensions changed]
```

This discipline is the single most important guardrail. Surprises that do not connect back to moat thinking go un-acted-on; the company drifts toward strategic obsolescence one un-examined event at a time.

### 2. Moat re-check (full transparency)

For each of the six moat dimensions, restate the prior-quarter assessment and the current assessment:

| Dimension | Prior quarter score | Q1 events | Current score |
|-----------|---------------------|-----------|--------------|
| Technical | Y / Maybe / N (X.X) | [events affecting this dimension] | Y / Maybe / N (X.X) |
| Data | ... | ... | ... |
| Distribution | ... | ... | ... |
| Regulatory | ... | ... | ... |
| Talent | ... | ... | ... |
| Time | ... | ... | ... |

Six dimensions, scored Y (1.0) / Maybe (0.5) / N (0). N/A is excluded from sum.

**Weighted total: prior X.X → current Y.Y**

### 3. Verdict and response

Apply the same verdict rules as the external skill, but with internal transparency:

- **Weighted total ≥ 3.0** → present the analysis to the board with the recommendation that the product itself needs reconsideration. This is uncomfortable but it is the right conversation to have at this level. Do not soften it.
- **Weighted total 2.0–2.5** → present the analysis with explicit mitigation actions for each Y / Maybe. The board should understand which dimensions are exposed and what the team is doing about each.
- **Weighted total ≤ 1.5** → present briefly as confirmation that defensibility remains a strength.

## Key differences from the external variant

The internal variant always shows the full weighted-score table. The external variant abstracts the analysis into a defensibility narrative for the public slide. The reason: board members need the full picture to be effective allies. Investors-as-prospects do not — they will form their own view.

## Insertion position

In a board update deck, the moat re-check chapter goes:
- After the "surprises this quarter" section
- Before the "strategy adjustments" section

The flow is: here is what surprised us → here is what it does to the moat picture → here is how the strategy is changing in response.

## Common errors

- **Reporting a competitive surprise without running the re-check** — this is the biggest internal failure mode. The team observes the surprise, mentions it in passing, and never reconnects it to the moat framework. Three quarters later the company is materially behind and it is unclear when the gap opened.
- **Running the re-check but burying it in an appendix** — at board level, this is a primary chapter, not a footnote
- **Soft-pedaling a Y verdict because it is uncomfortable** — board members should know which dimensions are exposed; their network and capital can help close gaps if they understand the situation

## Re-check vs first-time check

If this is the first internal moat-check (e.g., a Series A startup that did the full check during fundraising), reuse that prior analysis as the prior-quarter baseline. If no prior moat-check exists, mark Q0 scores as 🔴 `[needs-data — no prior moat-check on file; this analysis establishes the baseline]` and propose to make this a standing item.
