# Biotech Sub-flow: IP / Regulatory / Reimbursement (Internal Variant)

This chapter is mandatory only when the company is in the biotech / health-tech space — but its depth depends on product type AND on the level of the internal presentation.

## Step 1: Product type sub-routing

Same classification as the external skill:

| Product type | Examples | IP depth | Regulatory depth | Reimbursement depth |
|--------------|----------|----------|------------------|---------------------|
| **Therapeutic** | Small molecule, biologic, cell therapy, gene therapy | Full chapter | Full chapter (IND/NDA/BLA) | Full chapter (payer + coding) |
| **Diagnostic** | IVD, companion diagnostic, AI-based imaging device | Full chapter | Full chapter (510(k)/PMA/De Novo) | Full chapter (CPT application) |
| **Research / design tool SaaS** | DMTA platform, ELN, cheminformatics, lab automation software | Light (software IP only) | **N/A — short paragraph** unless 21 CFR Part 11 applies | **N/A — short paragraph** |
| **Clinical decision software (SaMD)** | CDS for clinicians, SaMD with treatment recommendation | Light (algorithm patents optional) | Full chapter (FDA SaMD/CDS rule) | Depends on integration target |
| **Service-based** | CRO, clinical network, contract research | Light | Depends on service type | Depends on service type |
| **Health-data platform** | RWE, patient registry, real-world data brokerage | Includes data-rights structure | Depends on HIPAA/GDPR/local privacy law | Depends on business model |

Confirm with the user if any classification is ambiguous. Record the result in the Mandatory Assumption Disclosure Table.

## Step 2: Apply level cadence

Internal presentations follow a different cadence rule for this chapter than external pitches do:

| Level | Cadence for biotech subflow |
|-------|----------------------------|
| Team weekly / dept monthly | Reference only — point at the standing biotech-status doc; do not reproduce |
| Department quarterly | Light update — only material changes from prior baseline |
| Board quarterly | Light-to-full update depending on activity — material changes always covered, full re-disclosure annually |
| Board annual / strategy off-site | Full re-disclosure |
| All-hands | Mention only in passing; full content lives elsewhere |

The instinct to fully re-cover IP / Regulatory / Reimbursement at every board update produces fatigue and dilutes the impact when something has actually changed. Reserve full chapters for the moments that warrant them.

## Subsection 1 — IP (Intellectual Property)

For internal updates, the IP subsection should cover:

### Quarterly board update (light)
- Any IP filings completed this quarter (with dates)
- Any FTO concerns identified or resolved this quarter
- Any pending decisions requiring board input (e.g., "We need to decide whether to file in Japan by end of Q2")

### Annual / strategy off-site (full)
- Complete patent portfolio review: applications / granted / PCT / national-phase entries
- FTO analysis status with counsel
- Patent landscape map
- Trademark, trade secret, know-how status
- Academic licensing terms if applicable

Internal disclosure should be more frank than external. If FTO is questionable, say so plainly — board members can absorb that and contribute. Hiding it makes them ineffective allies.

## Subsection 2 — Regulatory

### Quarterly board update (light)
- Last milestone accomplished
- Next gating event with timing
- Any regulator interactions this quarter (Pre-submissions, requests for information, etc.) — date and outcome
- Any newly identified regulatory risks

### Annual / strategy off-site (full)
- Complete regulatory pathway with all milestones plotted
- Pre-submission engagement history
- Risk register

For research / design tool SaaS at any internal level: a single line confirming "no change to N/A status" is sufficient unless there is a triggering event.

## Subsection 3 — Reimbursement

### Quarterly board update (light)
- Any payer engagement this quarter (advisory boards, early dialogues)
- Any coding strategy changes
- Health economics evidence collected this quarter

### Annual / strategy off-site (full)
- Payer strategy revisited
- Coding strategy with code-application status
- Pricing assumptions and the evidence supporting them
- International payment considerations

For B2B SaaS where reimbursement does not apply: confirm "still N/A" with one line, unless the company is changing markets.

## Common errors specific to internal disclosure

- **Underplaying regulatory delays to the board** — "still on track for IND in Q3" when in reality the pre-submission feedback has surfaced new requirements is exactly the kind of soft-pedaling that destroys board trust
- **Treating FTO concerns as something to "deal with later"** — board members are likely to have legal-savvy connections; surfacing FTO concerns early gets you help, hiding them creates cleanup work later
- **Treating reimbursement strategy as the commercial team's problem and excluding from board updates** — for any therapeutic / diagnostic / SaMD with insurance-paid customers, reimbursement is a board-level concern
