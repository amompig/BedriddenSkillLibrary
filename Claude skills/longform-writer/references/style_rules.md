# 寫作風格硬規則

writer 必須遵守的風格規範。Stage 1 樣本草稿、Stage 2 章節撰寫、Stage 3 自檢都依本檔。

## 核心原則

長文敘事為主。除明確例外，所有內容用敘述化段落表達。**避免條列化思維**——讀者要的是論證流，不是 bullet point summary。

## 強制性規則

### Rule 1: 開頭條列摘要

文章開頭可有「本文重點」「TL;DR」或同義段落，最多 5 點，每點 1-2 句：

```markdown
## TL;DR

- 過去十年量子相干態在生物系統的證據逐步累積，但仍有重要批評
- 光合作用 FMO 複合體的相干態觀測是核心證據
- 鳥類磁感的相干態爭議仍未定論
- 退相干理論的批評在多數實驗條件下仍站得住腳
- 此議題未來十年的關鍵實驗在於室溫條件下的可重複性
```

開頭摘要**不是**必要——若文章性質不適合（例如純文獻回顧的綜述），可以省略。

### Rule 2: 正文章節敘述化

章節內主體必須是段落式敘述，不允許單獨成段的條列。

❌ 不對：

```markdown
### 2. 退相干批評

退相干理論對量子生物學提出三個批評：

1. 室溫熱噪音應使相干態時間極短
2. 生物分子的振動與環境耦合難以隔離
3. 多數聲稱觀察到相干態的實驗無法獨立複現

這些批評來自多個研究團隊...
```

✅ 對：

```markdown
### 2. 退相干批評

退相干理論對量子生物學的批評可歸納為三個面向。首先是熱噪音問題：在室溫下，
熱擾動的能量遠超過量子相干態維持所需的精細條件，使任何相干態都應在皮秒時間尺度
迅速崩解 [Tegmark, 2000]。其次是耦合難題：生物分子內部的振動模式與環境溶劑分子
的能量交換密度極高，使得相干態的環境隔離在實驗上困難重重 [Wilde et al., 2018]。
最後是複現性挑戰：多項聲稱觀察到生物系統相干態的實驗，在獨立團隊嘗試複現時遭遇
顯著困難，這對該領域的知識基礎提出了質疑 [Olshansky et al., 2019]。
```

差異：條列形式把論點分割，讀者必須自己腦補論點之間的邏輯關係；敘述形式內建邏輯連接詞（「首先」「其次」「最後」「使得」「這對...提出了質疑」），讀起來流暢且論證緊密。

### Rule 3: 條列僅限例外場景

下列情境**允許**條列：

#### 例外 1: 章節內並列項目（前後須有敘述包裹）

```markdown
光合作用研究中，下列實驗系統反覆被引用：

- FMO 複合體（綠色硫桿菌的捕光天線）
- LH2 複合體（紫色細菌的外周天線）
- PSII 反應中心（高等植物的水裂解中心）

這三個系統具有不同的環境條件與時間尺度，但都觀察到類似的長壽命相干態。
這暗示量子相干可能是光合作用普遍的特徵，而非個別系統的偶然...
```

注意：**條列前後必須有敘述包裹**——前面說明這個 list 是什麼，後面繼續展開論述。

#### 例外 2: References 章節

References 永遠是 list 形式：

```markdown
## References

- Engel, G. S., et al. (2007). Evidence for wavelike energy transfer through quantum coherence in photosynthetic systems. *Nature*, 446, 782-786.
- Hore, P. J. (2016). The radical-pair mechanism of magnetoreception. *Annual Review of Biophysics*, 45, 299-344.
...
```

#### 例外 3: 表格類資訊

需要對照的資料用 markdown 表格，不要用 list：

```markdown
| 系統 | 觀察到相干時間 | 室溫條件 | 獨立複現 |
|------|---------------|---------|---------|
| FMO  | 660 fs        | ✓       | 部分    |
| LH2  | 530 fs        | ✓       | 是      |
| PSII | 200 fs        | ✗       | 無      |
```

### Rule 4: 引用標示

inline 用 `[author, year]` 形式：

- 單一作者：`[Engel, 2007]`
- 兩位作者：`[Engel & Lee, 2007]`
- 三位以上：`[Engel et al., 2007]`
- 同一年同一作者多筆：`[Engel, 2007a]`、`[Engel, 2007b]`
- 預印本：`[Smith, 2024, PREPRINT]`
- 學位論文：`[Smith, 2023, THESIS]`
- 機構報告：`[WHO, 2024, REPORT]`

References 章節列完整 metadata：作者、年、標題、期刊/venue、頁碼或 DOI。

### Rule 5: 語氣

學術冷靜。避免：

- 「我覺得」「我認為」「個人猜想」（學術寫作不用第一人稱主觀）
- 「事實上」（除非 followed by 客觀事實）
- 「值得注意的是」（多數情況用得太頻繁）
- 「不容忽視」（贅詞）

允許：

- 「本文認為」（明確表達文章立場時）
- 「依現有證據」「在目前認知中」（謹慎表達）
- 「This review proposes」（英文等價）

### Rule 6: 避免 GPT-ism 起手式

下列起手式禁用：

- 「在快速變遷的世界中...」
- 「在當今...時代...」
- 「眾所週知...」
- 「不可否認的是...」
- 「歸根究底...」
- 「Let's dive into...」
- 「In today's fast-paced world...」

替代：直接從具體議題切入。

❌ 不對：

```
在快速變遷的科學世界中，量子生物學作為一個跨領域的研究方向...
```

✅ 對：

```
量子生物學試圖回答一個核心問題：在室溫的混亂熱環境中，量子效應是否可能在生命過程中扮演功能性角色？
```

## 章節間銜接

每章開頭應與上章結尾呼應。範例：

```markdown
### 1. 引言
...（章節內容）...
這些觀察引出兩個層次的疑問：理論上量子相干態能否在生物系統存在，
以及若能，這對我們理解生命過程有何意義？下一節先處理理論層面。

### 2. 理論背景
延續上節提出的理論疑問，本節從退相干理論的核心預測談起...
```

不要：

```markdown
### 1. 引言
...

### 2. 理論背景
量子力學中的相干態概念...
```

第二個版本沒銜接，讀者會感到突兀。

## 用詞建議

避免重複用詞——同一段內勿用同一個動詞兩次以上。同義詞替換是基本功。

避免被動語態被濫用：

❌ 「相干態被觀察到於 FMO 中」
✅ 「FMO 中觀察到相干態」

但學術寫作有時被動是合適的（突顯動作對象而非主體）：

✅ 「樣本以 4°C 保存」（動作對象是樣本）

## 段落長度

- 一段不超過 200 字（過長讀者會迷失）
- 一段不少於 50 字（過短像條列偽裝）
- 章節內段落數：3-7 段為宜

## 中英混雜

- 主體語言依 structure 檔指示（中文或英文）
- 中文文章中英文 paper 名直接保留英文（不翻譯）
- 中文文章中專有名詞首次出現附原文括弧：「光合作用 FMO 複合體（Fenna-Matthews-Olson complex）」
- References 全英文 metadata（per W-8）

## 格式一致性

- 標題層級：H1 用於文章標題，H2 用於主章節，H3 用於子節，H4 用於子子節
- 強調：粗體 `**text**` 偶用，斜體 `*text*` 用於書名與外文
- 不要混用 `__bold__` 與 `**bold**`
